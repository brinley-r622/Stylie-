# Stylie-


# Overview
An AI personal styling assistant which recommends hairstyles and hair colors using face shape, hair type, and skin tone.

# Features
- Upload a clear selfie
- AI face shape detection
- AI hair type classification
- Ai skin tone classification
- Personalized hairstyles recommendations
- Hairstyles to avoid (if any)
- Styling tips
- User preference customization for more accurate results

# Built With 

- Python
- TensorFlow
- MobileNetV2
- Keras
- NumPy
- Pillow(PIL)
- Google Colab

# How It Works

User uploads selfie to stylie and the image is preprocessed.
Ai predicts the face shape, hair type, and skin tone.
User selects styling preferences
Stylie generates personalized recommendations
